## 写作流程

新建文章：

```bash
npm run new "文章标题" my-post-slug
```

它会在 `content/posts/` 下生成一个带 frontmatter 的 `.mdx`，默认 `draft: true`。
草稿只在 `npm run dev` 下可见，构建时会被过滤掉，所以可以放心把半成品推上去。

## 代码高亮

围栏代码块支持标题、行号和高亮行：

```ts title="lib/retry.ts" showLineNumbers {6-8}
export async function retry<T>(fn: () => Promise<T>, times = 3): Promise<T> {
  let lastError: unknown;
  for (let i = 0; i < times; i++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
      await new Promise((r) => setTimeout(r, 2 ** i * 100));
    }
  }
  throw lastError;
}
```

行内代码写成 `const x = 1` 这样。

## 数学公式

行内公式 $O(n \log n)$，独立公式：

$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n) = O(n \log n)
$$
